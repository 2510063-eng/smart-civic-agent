# 1. Current Project Goal

Build an AI-powered civic issue resolution system that can:

REPORT
→ UNDERSTAND
→ DECIDE
→ ACT
→ MONITOR
→ FOLLOW UP
→ ESCALATE
→ VERIFY
→ CLOSE

Core concept:

**EVIDENCE → DECISION → ACTION → MONITORING → VERIFICATION**
